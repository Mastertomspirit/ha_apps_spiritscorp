Interne Endpunkte für Home Assistant & Grafana

Nutze im Home Assistant Docker-Netzwerk direkt den Hostnamen der App. So muss Port 9009 nicht ungesichert in deinem Heimnetzwerk geöffnet werden:

Home Assistant Prometheus Remote-Write URL:
http://localhost:9009/api/v1/push
Grafana Datasource URL (Prometheus):
http://localhost:9009/prometheus
Relativer Ingress Health-Check Endpunkt:
./proxy/mimir/ready
Interner Ingress-Pfad: proxy/mimir/services
Interner Ingress-Pfad: proxy/mimir/config

Home Assistant configuration.yaml Snippet

Füge diesen Block in deine /config/configuration.yaml ein, um Sensorwerte ohne zusätzliche Scraper in Mimir zu speichern:

prometheus: namespace: homeassistant component_config: sensor: override_timestamp: true filter: include_domains: - sensor - binary_sensor - climate - switch - light exclude_entity_globs: - sensor.*_last_seen - sensor.*_uptime default_metric: homeassistant_sensor
In die Zwischenablage kopiert!
